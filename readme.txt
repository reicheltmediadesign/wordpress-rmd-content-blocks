Content blocks for the block editor: page links, recommendations, parallax image, quote band and surfaces.

== Description ==

RMD Content Blocks adds blocks for recurring content patterns. All blocks are rendered on the server, so saved content stays valid when the markup changes; themes adapt the look through CSS custom properties.

* Page links: up to three cards to other pages; image and label come from the target page, optional anchor.
* Recommendations: cards for external offers with automatic affiliate disclosure (badge, rel="sponsored", notice below the cards).
* Parallax image: a picture that drifts slower than the page while scrolling, in several heights, shapes and motion strengths, with an optional sentence on top.
* Quote band: one sentence in large, light type on a coloured band across the full width.
* Surfaces: a "Surface" panel for the Group block and the quote band; the theme defines the surfaces.
* Migration: Tools → Content blocks replaces blocks a theme used to register with these blocks.

== Installation ==

1. Upload the plugin zip under Plugins → Add New → Upload.
2. Activate the plugin.
3. Insert the blocks from the "Design" category of the block inserter.
